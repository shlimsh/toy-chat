# Datadog Synthetic Monitoring

## 테스트 유형
Synthetic Monitoring은 실제 사용자가 문제를 경험하기 전에 외부 관점에서 애플리케이션을 주기적으로 점검한다. API Test는 HTTP, SSL, DNS 같은 Endpoint를 검증하고 Browser Test는 실제 브라우저에서 사용자 시나리오를 실행한다. 테스트는 여러 위치와 주기로 실행할 수 있다.

## Browser Test 구성
Browser Test의 Step은 클릭, 입력, 요소 대기, Assertion, JavaScript 실행, HTTP 요청 같은 작업으로 구성된다. 선택자는 화면의 고정 좌표보다 안정적인 속성을 우선한다. 동적으로 생성되는 예약 번호처럼 다음 단계에서 재사용할 값은 요소의 텍스트를 변수로 추출한 뒤 해당 변수를 사용해 일치하는 요소를 찾는다.

로그인이 필요한 테스트는 로그인 단계를 직접 기록하거나 인증 상태를 재사용하는 방법을 검토한다. 테스트 계정과 비밀 값은 일반 문자열보다 안전한 Global Variable 관리 방식을 사용한다.

## 실패 분석
실패 Step의 스크린샷, 네트워크 요청, Console Error, 요소 탐색 결과를 함께 본다. 네트워크 오류는 DNS, 연결, TLS, Timeout, 대상 서버의 4xx/5xx를 구분한다. 단순히 Target Element가 없다고 판단하기 전에 이전 Step에서 페이지 전환과 데이터 생성이 완료됐는지 확인한다.
